# Claude/Codex Pet

## 项目需求

- 做一个桌宠，能够实时检测Claude/Codex CLI的对话流，根据不同状态表现不同的动作。

## 具体实现

- 人物设计：
1. 直接采用开源项目Live2dOnWeb，需修改原项目使得背景透明。
2. 人物模型直接用下载好的模型文件，位置character文件夹中.

- 检测对话流：
1. 检测stream-json，捕获对话流的内容。
2. 检测Hooks，捕获当前agent状态：
   - 待机：用户无操作，agent无工作，用户正在输入。
   - 工作：agent工作时候的一切行为。
   - 输出：工作结束后agent输出文本。
3. Codex的对话流通过codex exec --json或者app-server获取。

- 页面显示：检测到的对话流内容在动画下方显示，如果是Claude的，则以橙色深色为毛玻璃特效背景，显示对话流内容；若是Codex的，则以蓝色深色为毛玻璃特效背景。显示框为圆角矩形，400米跑道那个样子的。
